# Code of conduct

Part by Part follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in issues, pull requests and anywhere else you speak for the project.

The short version: be kind, assume the other person means well, and criticise
the work, not the person who did it. Harassment, personal attacks and posting
someone's private information have no place here.

## Reporting a problem

If something here makes you feel unsafe or unwelcome, report it through the
project's
[private report form](https://github.com/abhinavbolla/part-by-part/security/advisories/new)
and start the title with "Conduct". Only maintainers can read it, and it works
with any GitHub account.

You'll get a reply within 7 days, and the report stays confidential. If it is
about a maintainer, use [GitHub's abuse form](https://github.com/contact/report-abuse)
instead.
