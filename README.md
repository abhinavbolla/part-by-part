# pc-builder

A website for building a PC part by part, as if assembling it for real: pick
real components, seat them in the case, and watch the build come together.

`pc-builder` is a working name.

## Goals

- Real parts: CPU, motherboard, RAM, GPU, storage, PSU, case, coolers, fans, cables.
- Assembly, not a checklist: parts are inserted into place and animate as they seat.
- Compatibility that matches a real build: sockets, form factors, clearances, power.
- Very low latency, measured rather than claimed.

## Status

Planning. Nothing is built yet.
